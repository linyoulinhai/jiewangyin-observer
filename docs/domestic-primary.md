# 国内主用：先让普通手机用户拿得到文件

更新：2026-10-09。下面是实施顺序；国内网盘、文档和社交发布尚未代你开通或上传，仍由你处理。

部署与资料库先见[最新核对与排序](deployment-options.md)。EdgeOne临时预览与CloudBase默认测试域名不当作长期宣传入口，先确认正式域名与账号条件。

日常只维护四件事：**一个可阅读入口、一处可下载目录、一份另存文件、一名接力者**。跨境账号与VPN不作为普通读者必须完成的步骤。维护端GitHub可继续保留，读者能否直连要实测，GitHub链接不能是唯一准入。

1. **阅读入口**：腾讯文档、飞书或WPS任选已有账号中一种，放简短介绍、机构目录、最新版本、下载与更正入口；同时提供CSV/TXT可另存。现有原站也保留，国内手机测试后决定是否主推。
2. **公开下载入口**：现有国内网盘选择一个放小目录/网站包，选择一个不同运营方的空间放获准转交的图片视频包。蓝奏适合作为小包候选；123、移动、天翼等作为媒体包候选。单文件格式、容量、免登录条件、速度和费用都以你的实际账号与接收测试为准，没有承诺不限速免费。
3. **可复制内容**：微信/QQ转交TXT＋小ZIP；微博、贴吧、知乎、小红书用同一批短介绍和图文稿；B站、抖音、视频号用公开播放版。无外链的平台提供可搜索项目名与具体查找办法。每份保留出处、作者、版本；不依赖短链或套壳轮换绕过平台处理。
4. **本地副本接力**：接收者真正另存到手机文件目录，再交另一位参与者保管；近距离可尝试USB或LocalSend。无人另存的转发次数不计为备份。

免费起步不同时注册几十个账号。先发布一份、下载一次、转交一次、完成一次版本更新，再扩渠道。主用入口不可达时，用同版本的TXT/CSV/ZIP更换已验收的入口，不要求用户重新理解资料结构。

一次手机验收至少记录：网络与设备、是否需要登录/客户端/会员、实际下载文件名和大小、保存后能否打开、有无速度或流量收费、另一设备能否再取得。表格见`docs/promotion-kit/渠道验收记录.csv`。运营方相同、账号相同或同时失效的空间不要计作独立保障。

新的[资料源与审核导出流程](replicable-workflow.md)使每位维护者可从公开JSON重建自己的整理索引。网盘只有预览页、社交平台只有转码视频时，还缺完整可复制副本。优先保存你可以合法再分发的源数据与文件。

原84项路线全部保留在[完整目录](multiplatform-distribution.md)；机器目录`channel-catalog.json`新增`access_tier`。`domestic-candidate`只是国内主用候选，绝不表示已经测试成功。技术方案的部署地点另行决定，不按开源工具产地判断国内可达。

[跨境/特殊网络条件备用](overseas-backup.md)单独处理，继续保留。
