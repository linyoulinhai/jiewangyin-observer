# 手机宣传与网盘交接包

版本：2026-10-09 / promotion-2，沿用promotion-1图文素材。此目录是可复制的宣传材料，尚未代你投放社交平台或上传网盘。

新版增加[国内主用](../domestic-primary.md)、[跨境与特殊网络条件备用](../overseas-backup.md)、[公私两库与数据源复制](../replicable-workflow.md)；ZIP内另附“接力流程”三份TXT。整包另存与更新副本作为接力要求，GitHub不作为国内手机用户唯一步骤。

普通用户从 `先读我.txt` 开始；用浏览器打开 `index.html` 可以看三张图、复制文案和找到下载。手机文件预览器可能不能运行网页按钮，此时直接打开TXT或保存PNG。不要把HTML预览作为唯一使用办法。

## 可以直接使用

- `评论区与短介绍.txt`：有链接、无链接、相关话题补充、回答操作问题、聊天转交等版本。
- `图文发布稿.txt`：三张图的顺序、完整正文与来源致谢。
- `cards/01-introduction.png`、`02-sources.png`、`03-save-and-share.png`：1080×1440可直接上传图文的图片；同名SVG是可编辑源文件。
- `site-qr.png`：原站网址二维码，只作便捷入口；完整地址在文案与导读中保留。
- `视频口播.txt`、`视频字幕.srt`：30秒图文视频的口播与字幕。发行附件另提供无声音的竖屏预览，不冒充真实经历或已经拍摄的操作录像。
- `志愿协作任务.txt`：可直接发布的小任务与交接要求。
- `网盘上传步骤.txt`、`接下来由你完成.txt`：手机上传、分享设置、独立副本与接收者测试。
- `渠道验收记录.csv`、`公开链接登记模板.json`：记录实际测试，未测项目保留“未测”。不填手机号、密码、回执或私人原件链接。

图片仅用本站自己编写的图形与文字，无真实受害者肖像、具体机构指控或第三方建筑照片。图中文字强调来源待核对；二维码指向现有原站，不指向短链。PNG和SVG均保留来源致谢，字体使用本机Noto Sans CJK渲染，图片不附带字体文件。

## 重新生成

`scripts/build-promotion-assets.py` 生成原生SVG、PNG及二维码，依赖Pillow与qrcode 8.2。使用本机已有中文字体，也可通过 `--font`、`--bold-font` 指定路径；不需要上传素材到第三方。

`python3 scripts/build-promotion-package.py --output /仓库以外的新目录/宣传与网盘交接包.zip` 使用公开白名单打包，包含本站已有公开网站ZIP、来源表格和许可证。不自动上传、发评论或收集浏览者数据。
