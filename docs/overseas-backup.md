# 跨境与特殊网络条件备用：保留，但不挡住手机主流程

更新：2026-10-09。VPN/其他特殊网络条件相关渠道按备用管理，不删除。实际可达性随地区、网络、域名与服务变化，本项目未做国内真机验证，不一概声称全部必须VPN或一定直连。

- **源码与发行备用**：GitHub仓库、Releases、Pages、LFS；GitLab、Codeberg和各自Pages；Internet Archive。GitHub已建立源码及发行，其他是候选；LFS没有开通付费额度。公开下载不得附上私有库密钥。
- **境外展示与社群**：YouTube、PeerTube、Reddit、Mastodon/Bluesky、Telegram、Discord。展示经授权内容并保留来源；社群聊天和平台视频不能成为完整原件唯一副本。
- **境外文档与文件备用**：Notion、Proton Drive、Google Drive、OneDrive、Dropbox、MEGA。OneDrive等具体入口国内可达性可能不同，按备用统一登记并逐项测试。只有获准公开的包才能建公开分享，私人加密备份须与公开分享分开。
- **境外或跨境托管候选**：原Sites站、Cloudflare Pages/R2、Netlify、Vercel、Neocities、Surge。原站已上线但国内手机可达性未验收；免费额度、用途和账单分别检查。Cloudflare技术与国内运营商服务不混为一条可达性结论。
- **依部署而定**：TiddlyWiki/Tiddlyhost、FeatherWiki、Miraheze、DokuWiki、MediaWiki、Discourse、Forumotion、PairDrop/ShareDrop、Syncthing、BitTorrent、IPFS、邮件与已有公益栏目。离线单文件/自托管服务和境外托管平台的条件不同，先确认部署点。IPFS要有实际持续保存的节点或服务，不能把CID当成永久存储承诺。

备用维护者取得**同版本的公开快照、许可、媒体索引、小包与散列**，再上传自己有权操作的空间，登记版本和文件哈希。由维护者自行处理网络与账号；普通国内读者应仍能通过[国内主用路线](domestic-primary.md)取得同一份文件。

不要把不同平台的视频转码版本的散列与原件散列混用；不同格式视为不同媒体副本。更正后同步备用镜像的当前版和更正说明；必要时清理你可控制的违规旧副本。已流转副本无法保证全部撤回。

完整84项方案仍见[原多平台指南](multiplatform-distribution.md)。本文做使用分层，未自动注册、开通、购买、上传或联系任何第三方。
