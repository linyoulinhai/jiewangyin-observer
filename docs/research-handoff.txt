使用方法

如果有目标机构，把机构名称、省市、已知链接补在提示词开头；没有目标也可
先让 Grok 从有可追溯公开来源的机构开始，每批研究 3–5 家，再继续补充。
查询完成后保存完整回答和来源清单，把结果交回本项目做人工核对与整理。
本 README 是研究任务说明，未开展真实资料查询，未录入任何真实指控。


一、可直接交给 Grok 的提示词

【提示词开始】

请帮我为“看见”项目查找真实、可追溯的公开资料。

项目用途：非营利的戒网瘾机构资料展示与互助网站，服务范围为中国大陆，
本次查询不含台湾地区。核心是让机构资料、相关图片视频与经历便于查阅、
保存和传播。网站面向手机用户，机构名称、地区、影像和资料来源是重点。
现有概念网站的机构档案与经历均为虚构演示，不能作为真实研究的来源。

研究目标：了解相关机构身份与历史、公开的争议或事件、各方陈述及回应、
可核对的官方文件、媒体调查、视频和评论线索。请保留有利、不利及矛盾资料，
不要预设所有机构违法，也不要用评论数量、情绪或转发量判定事实。

本批目标机构或地区（可选，由我补充）：
机构名称／曾用名：未指定
地区：未指定
已知视频或网页链接：未提供
重点时期：未指定；请区分历史事件和当前状况

如果我没有指定机构，请先找出有原始公开来源可追溯的少量研究对象，
每批 3–5 家。这只是分批工作方法，不是全国机构总数，也不是完整覆盖。

1. 查询范围与关键词

优先查：抖音、B站的具体公开视频及其评论区；小红书的具体公开笔记及其
评论区（招生广告、亲历叙述、讨论帖均可作线索）；同时查官方公开信息、
原始新闻报道、机构自身公开页面、微博、贴吧及其他能追溯原出处的资料。
帖子和评论用于发现线索，需要与其他来源核对。

可组合使用：
戒网瘾／戒除网瘾／网瘾学校／网络成瘾／青少年特训／叛逆学校／
行为矫正／封闭式教育／军事化管理／特训学校／问题少年学校。
这些词是检索入口，不表示搜到的机构一定属于项目范围或存在问题。

再组合省、市、区县、机构全称、简称、曾用名，以及：
经历／亲历／调查／投诉／回应／澄清／处罚／判决／停办／更名／迁址。
先广泛发现候选，再围绕明确机构核对；不要只反复搜索负面用词。

2. 机构身份核对

为每家机构分别记录：公开名称、登记主体名称（若能查到）、曾用名、
省市区县、公开经营或办学场所、资料涉及的活动时期，以及各字段的来源。
不要收集工作人员家庭住址、私人电话号码或其他无关私人信息。
名称相似或同名的机构先分别列出；更名、迁址、分校、关联主体等关系必须
附来源，不要凭同名、相似标识或一条评论直接合并。
“曾经经营”“现仍经营”“已停止”要分别有对应时期的来源；状态查不到就
写“当前状态未核实”。旧照片、旧事件不能证明现在的业务或状况。

3. 视频与评论区是本次重点

每个视频至少记录：平台、原始页面链接、平台视频 ID（确实可见时）、
标题、公开发布者或来源名称、原发布时间、实际查阅时间、视频涉及的
机构和时期、内容摘要，以及与相关主张对应的片段时间点。
字幕、配音、标题、拍摄画面和发布者自述分别辨认；不要把视频上传日期
直接当作事件发生日期，也不要从外景画面推断画面外发生过什么。
优先找到原发布页面；二次剪辑、搬运视频须注明，并查找原出处。

每条重要评论都要关联所属视频，记录：
所属视频链接和 ID；评论可定位链接或 ID（能获取时）；评论内容的准确摘要；
评论发布时间；是否为回复；父评论／对话上下文；必要的短摘录及定位信息。
如某条评论声称亲历、转述他人或只是推测，请分别标注为“自称亲历”
“转述”“推测”；身份未核实，不因语气像亲历就认定其真实。
无需批量建立评论者个人资料；只在溯源必要时记录公开署名，不补充其头像、
联系方式、家庭、学校、健康或其他个人画像。

能直接查看评论才记录已查看；只能看到搜索摘要就标“仅搜索摘要”。
评论不能访问、需要登录、分页不全、回复没展开，都要注明限制。
不要声称采集了全部评论；缺失内容不能直接认定为被删除、被压制或违法。
如果没有实际访问抖音/B站/小红书评论的能力，请明确说出，并给我需要在手机上
人工查看的具体视频或笔记链接、查找位置和待核对问题。不要虚构评论原文或 ID。

小红书每条笔记至少记录：平台、原始 explore 页面链接、笔记 ID（可见时）、
标题、发布者昵称、原发布时间、实际查阅时间、涉及机构与时期、内容摘要；
评论同样关联所属笔记，并标注自称亲历/转述/推测。机构招生笔记标明「机构宣传」，
不与亲历混写。本地采集工具见：./工作区/tools/README-工具链.md

4. 图片和视频保存、展示所需资料

每张候选图片、每段视频都建立独立条目：原始页面、媒体链接（确实取得时）、
作者或上传者、拍摄／事件日期（若有）、上传日期、对应机构、画面内容、
是否原件／转载／剪辑、是否有公开许可及许可原文链接。
视频截图须写明视频来源和截帧时间点，说明是截帧，不冒充独立现场照片。
可优先寻找机构公开外景、公开文件、新闻画面等与档案相关的素材。
避免让可识别的受害者、未成年人或无关人员成为未经确认授权的公开封面。
公开页面可访问，不代表图片、视频和评论可以自由整份转载；没有明确许可
时写“使用许可未核实”，仍可把来源链接作为线索交付。
没有实际下载就标“仅链接”；没有取得授权就不要标“可转载”。
如确实保存了文件，请记录文件名、原始来源及已有的校验值；不要编造
文件大小、下载成功、截图、授权或 SHA256。文件保存状况单独列出。

5. 按具体主张整理，不直接给机构定性

把“某机构发生过某事”拆成能核对的具体主张。每条主张列：
谁在何时陈述；陈述指向的事件时间；原始来源；能支持到什么程度；
是否有其他独立材料；机构回应／更正；矛盾之处；仍需查证的问题。
多篇转载同一个报道或同一段视频，只算同一来源链，不能当作独立佐证。
官方文件、新闻报道、个人陈述、评论、你的分析分别注明来源类型。
官方文件要写发布机关、文件日期、编号（若可见）、涉及主体及程序性质。
投诉、调查、处罚、裁判及其最终状态分别记录；不要把一次投诉当作正式
认定，也不要把与你研究的主体或事项无关的文件套到机构身上。
逐条区分来源原文、你的概括和推断。短摘录保留语境，不整篇复制文章。

6. 对找不到和证据不足的处理

请分别使用下面的描述，不把不同情况混在一起：
未检索到：在写明的检索范围中暂未找到，不能据此认定不存在。
未能访问：链接存在但无法直接查看，说明登录、失效或能力等具体限制。
有来源陈述、证据不足：找到了说法，但不足以支持相关事实结论，写明缺口。
存在相互矛盾资料：分别给出处，不能擅自择一当作事实。
有材料支持：明确材料支持的具体部分；真实发布前仍需项目维护者复核。

如果实际能力无法完成任务，不要用看似完整的答案填空。说明已做了什么、
未完成什么，列出我可以继续人工查找的入口。

7. 请按下面结构交付

A. 本批查询说明
实际查询日期和时区、研究对象、检索词、查过的平台与页面、可访问范围、
登录或其他限制。区分你直接看到的内容、搜索摘要和转引内容。

B. 机构条目
每家机构单独一段：机构名称、别名与身份关系、地区、涉及时期、当前状态、
各项来源编号、待核实事项。来源编号是本次整理的内部编号，不是平台 ID。

C. 来源与媒体清单
一条视频／网页／文件／图片／评论一条记录。至少包含：
内部资料编号；所属机构；资料类型；平台或发布单位；标题或短摘要；
来源 URL；平台 ID（未知留空）；原发布时间；事件时间（未知留空）；
实际查阅时间；直接查看／摘要／转引；所属视频及父评论；视频片段位置；
来源陈述摘要；授权和文件保存情况；限制；待核实问题。
评论的链接只能到视频页面时，要写“视频级链接，无法直接定位评论”。

D. 具体主张与核对清单
每条主张引用相关来源编号，说明支持、反驳或尚不能支持的部分。
单独列出仍缺少什么，以及下一步需要查看的链接、文件或上下文。

E. 面向手机展示的候选内容
每家机构建议一个中性名称、一句有出处的简介，以及最相关的图片／视频
候选来源。候选封面注明授权状态；未经核对不将个人指控写成已确认简介。

请先用清晰的文字和逐条字段交付，方便我复制保存。能另附 UTF-8 JSON／CSV
更好，但不要为了填满格式编造缺失数据。每个链接应指向具体来源页面，
避免只给平台首页或搜索结果。先完成这一批，再继续下一批。

【提示词结束】


二、把查询结果交回本项目

1. 最少交回：Grok 的完整回答＋逐条来源链接＋查询日期＋未解决的问题。
   不必先掌握 GitHub 或编程。普通文字、JSON、CSV 都能作为人工整理输入。
2. 来源原发布时间、事件发生时间和采集／查阅时间分开保存；未知就保留未知。
3. 真实机构单独建条目，不用“示例机构 A”等现有虚构资料的编号覆盖。
4. 我们先核对机构归属、链接、原文语境和媒体使用条件，再整理公开版本。
   原始经历、联系人、授权记录及可能识别个人的资料留在私有审核材料中。
5. 公开站点需要能够分享、复制和下载；每份公开材料应保留来源、版本日期、
   更正说明和使用条件，便于后续更新副本。

资料不必一次找齐。首批能核对的机构与影像资料比没有出处的全国汇总更有用。


三、与现有程序对接

现有程序说明：../tools/线索收集工具/README.txt
它支持本地 JSON／JSONL 的视频与评论导入，不自动公开。
Grok 输出的研究报告不是已经验证、可直接导入的记录，需要先转换字段。
本 README 不要求 Grok 使用平台 API，也不保证 Grok 可访问所有平台内容。

转换时主要字段为：
platform：douyin、bilibili；小红书在研究清单中用 xiaohongshu（当前线索工具
尚未导入，先保留在来源 JSON/CSV，字段同 README 第三节 C）。
kind：video 或 comment。
video_id：实际抖音数字 ID 或 B站 BV／av 号；未知不伪造。
comment_id：实际评论 ID；未知时作为普通研究线索保留，不强行导入为评论。
parent_comment_id：真实父评论 ID；没有或未知时不编造。
source_url：实际来源链接；短链需要另外确认视频 ID，程序不会联网解析短链。
text：保留来源语境的文字；不把研究者结论混进来源原文。
source_published_at：可确认的带时区 ISO 发布时间；未知为 null。
captured_at：实际查看／采集时间，带时区 ISO 格式；不是运行转换脚本的时间。

只有日期、没有确切时间／时区的来源，在完整研究记录中保留原始日期文字；
不要强补零点或默认时区伪装成精确发布时间。机构关系、主张核对、授权和
媒体清单另行保留，当前程序导入不会保存研究报告的全部字段。
私有线索队列不放进静态网站目录，不打包进公开整站 ZIP。
