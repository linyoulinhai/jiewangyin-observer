# 原站开发说明归档

以下来自原站2026-10-09的实施说明。这里所说的根目录私人库和研究工作区未上传；运行和部署请以[当前部署说明](download-and-deploy.md)为准。

# 戒网瘾机构观察：来源档案与经历互助

机构首页展示1251份已有来源记录，支持地区、城市、名称及别名查找。主题覆盖戒网瘾、特训和封闭矫正相关目录；来源收录不等于主体、主题相关性、现状或违法事实已经核实。

## 直接查看

原站： https://kanjian-archive-concept.chengbiliu3.chatgpt.site/ （开放游客浏览；互助发帖与回复需登录）
互助：`#mutual`；自己的内容：`#account`；公约：`#community-rules`。
管理员在“我的”中进入审核。原有 `#review` 只是虚构档案的流程示例。

来源目录来自本地已有NCT与PanDefenseProject资料，逐条保留编号和出处，均标为待核对。原有虚构机构、经历和媒体演示另行标注，AI示意图不配给真实目录机构；独立真实来源照片按其许可使用。互助实际提交内容标注“用户陈述，未作事实认定”，不会自动成为已核实机构资料。

## 核心流程

1. 平台登录，设置公开昵称并阅读公约。
2. 写标题、背景和分类；地区、机构、来源及媒体选填。先保存服务器草稿，再提交。新用户首主题、机构争议、疑似私人信息和新公开附件进入待审。
3. 未提交草稿仅作者访问；提交后管理员可查看附件。附件默认仅供审核，公开与传播需分别选择。它不会自动脱敏。
4. 管理员检查公开范围与来源，允许展示、要求修改或暂时隐藏，并填写原因。作者查看通知及处理说明，受到隐藏/修改处理时可申诉。
5. 普通回复可引用同一主题的已公开回复，关注后续、更新进展；服务器控制频率，异常讨论可慢速回复。举报数量不自动删除或封号。
6. 导出只包含每位提交者分别允许传播的公开正文、回复与附件。单帖附件累计不超过20MB时生成含离线HTML、JSON、媒体、来源和SHA256清单的ZIP；超过时下载来源目录并逐份保存文件。

## 保存与复制

- `dist/site-copy.zip` 是公开静态档案与界面的完整文件包，解压可浏览档案；上传静态空间即可展示。**它不包含线上论坛数据与后台，无法仅靠这个包复制完整论坛。**
- 单帖公开包由互助页生成，能独立阅读；其原站链接供核对后续更正。
- `/api/community/export` 当前最多导出200个获准传播主题的文字与附件目录，返回 `complete`；超限时不应当作全量备份。
- 私人账户、草稿、审核记录保存在D1；原件保存在R2。管理员可在 `#backup` 分页读取14张表、双次检查变化，使用本机密码加密保存数据库和4MB原件分卷。备份前暂停写入；这是应用层检查，不是跨表事务快照。密码遗失无法恢复，私人备份不能公开。
- `scripts/restore-private.mjs` 在全卷校验后恢复到新本地SQLite目录，逐卷处理原件，不将所有视频同时载入内存。它拒绝覆盖已有目录；未提供线上D1/R2一键切换。表结构及说明可从备用入口下载。
- 静态档案公开包与论坛授权导出包有不同许可范围；帖子作者不能替回复者授权。旧副本无法保证完全撤回。

## 项目结构

- `dist/`：静态档案和轻量页面；`community.js` 为互助交互。
- `worker/community.js`：真实API、作者权限、管理员处理、配额和导出。
- `db/schema.ts`、`drizzle/`：数据库表及生成迁移。已经应用的迁移不得改写。
- `scripts/preview-community.mjs`：仅绑定本机的模拟身份预览；测试登录路由不会放进生产Worker。
- `scripts/local-adapter.mjs`：预览/测试的SQLite适配器。
- `scripts/build-community.mjs`：将页面复制到 `dist/client/`，构建 `dist/server/index.js`。
- `scripts/package-public.py`：按明确白名单创建公开ZIP，排除DB、原件、凭证和服务端文件。
- `tests/community.test.mjs`：真实SQLite结构上的权限、审核、附件、导出、限流与申诉测试。

## 本机操作

需要Node.js 24（本机预览使用node:sqlite）与Python 3；开发者执行：

```sh
npm ci
npm test
node scripts/check-concept.cjs
node scripts/preview-community.mjs
```

访问 http://127.0.0.1:8770/ 。本机测试用户和测试管理员入口由终端显示；本机登录是模拟，不代表外部认证完成。测试产生的DB和附件存放于被Git忽略的 `.preview/`，不进入发布或公开下载包。

改数据库后先运行 `npm run db:generate` 并检查SQL；公开文件改动后运行 `python3 scripts/package-public.py`；随后 `npm run build`。Sites发布使用绑定的同一项目与原访问范围。

## 当前认证与试用限制

此版使用托管平台提供的ChatGPT登录身份，国内手机号身份认证尚未接入。生产Worker只能位于会验证并覆盖 `oai-authenticated-user-id/email` 的可信平台分发器后；**直接搬到外部公开Worker并信任来访者同名HTTP头会造成身份伪造。**独立部署完整论坛必须更换可信身份入口，不能直接照搬本机模拟身份。

管理员通过平台已验证的站点所有者邮箱，在Sites设置服务端secret `MODERATOR_EMAIL`；不要填写到前端、源码或公开包。邮箱不写入公开帖子和导出。仅持有平台服务访问令牌的请求不获得用户发帖或审核身份。

试用参数：新主题每分钟1次、24小时最多2个；回复每30秒1次、每日最多15条；单图10MB、单视频50MB，每帖6份/100MB，账号500MB，本站1GB。留存附件的累计占用仍计配额，撤回不会立即释放。不是全国正式运营容量承诺。无私信、收费、点赞积分榜或自动按举报数量封号。

未完成：国内公众身份认证与可达性验证、真机微信/iOS/Android大文件测试、自动脱敏、线上灾备切换及删除周期、大视频可播放切段/合成、抖音/B站真实采集联调。现有媒体工具仅按字节分包还原。真实材料收集另见根目录 `资料查找/README.txt`，不应将未经核对的搜索结果直接公开。

## 本地资料库与来源目录

完整私有资料库在项目根目录的 `本地资料库/`，含SQLite、独立HTML目录、1251份机构条目JSON、原始文件副本、35组同名候选关系与私人备份ZIP。保留旧1000条及溢出的251条；同名候选未强行合并。原始955条NCT、190条PanDefense JSON及190条CSV分别保留，以上是来源记录数量，不是确认后的独立机构数。

构建程序为根目录 `资料查找/工作区/scripts/build_local_library.py`。网站仅接入名称、别名、粗粒度地区、编号及出处。联系信息、负责人、原始举报摘要、私人经历及详细地址留在本地库，不进入站点或公开ZIP。原始媒体候选若仅为链接就保留链接，未宣称已下载图片视频。NCT的Unlicense及PanDefense的AGPL-3.0许可、处理代码和出处一并保存。

## 多入口收件与备用保存

`#provide` 支持本机草稿、私人ZIP、服务器草稿、明确提交与私人回执；`#feedback` 是独立私人更正队列。未提交草稿不向普通用户或审核者开放。平台登录账号可关联记录；回执是访问凭据，不是实名认证。站点访问范围已按用户要求开放游客；公开浏览与下载无需登录，私人资料仍按回执或作者身份鉴权，互助写入需登录。国内可达性仍须实机验证。

管理员在 `#intake-mod` 核对来源和公开范围；需要人工编辑公开版本，选择每个获准公开的附件后才能发布，反馈不能直接发布成机构档案。撤回隐藏关联公开内容，留存原件仍计空间，不保证旧下载副本被删除。附件流式计算SHA256；单图10MB、单视频50MB，每份6个/100MB，互助与资料收件共用全站1GB试用额度。

`#access` 提供独立离线投稿HTML、来源HTML/CSV/JSON、静态站复制包、离线草稿导入及管理员加密备份；浏览器缓存只包含公共界面，不缓存API、回执或私人记录。备用站点配置尚无独立在线镜像，不能把多个下载格式称为多个上线站点。

## 游客入口（2026-10-09）

访客直接打开机构首页，无登录拦截。顶部“登录”（登录后为“我的”）进入选择页，“游客进入”直达机构目录。游客能使用资料目录、公开讨论及获准传播的下载，也能提交私人资料与反馈、凭回执读取进度；互助发帖回复仍需账号。已登录用户可在“我的”点击“切换为游客”，通过平台退出登录后回到机构首页；不创建共享游客账户，不赋予审核权限。服务端的作者、回执和管理员鉴权保持有效。

## 导航整理（2026-10-09）

桌面主导航为下载、资料、互助；手机底部为下载、资料、互助、我的。机构首页保留为打开网站的首页，点击站点标题返回。顶部“登录／我的”紧邻“提供资料”，手机和桌面都直接显示；“更多”集中经历、私人回执、反馈和关于。下载进入 `#access`，公开目录、CSV与网站副本位于页面最前，保留离线整理与备用网址。原参与页与旧地址保留。菜单支持键盘、Esc关闭、点击外部关闭和选择链接后收起。页面选中状态按主功能归属设置，投稿与关于页不误标为互助。

响应式检查同时修正details地区地图：桌面自动展开，桌面切手机时收起，手机仍能手动展开。
