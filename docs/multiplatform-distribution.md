# 多平台传播、资料保存与备用办法

更新：2026-10-09。预算优先0元，后续确需支出时总预算不超过50元/月；没有自动充值或已购买新服务。

项目需要让不同平台的用户直接看到内容、保存副本和接力维护。因此传播稿、可下载文件和可重建网站都要准备，不只给一个GitHub地址。

可直接使用的[宣传与网盘交接包](promotion-kit/README.md)已补上评论区短文、图文卡片、二维码、视频脚本/字幕、志愿任务和手机网盘步骤；[接下来由你完成](promotion-kit/接下来由你完成.txt)标明账号、实际上传、公开分享与下载测试。原有全部84项路线继续保留。

**实际已建立的渠道目前是原站、GitHub仓库/Release和本地公开包；其余是保留的具体路线与待测入口，没有假装已经开通。** 下列数量是平台和形式条目，同一厂商的不同产品不能直接算独立备份。

## 先做成普通人能转交的一份材料

每次发布准备：短介绍TXT、平台图文/视频原稿、机构来源编号与更正说明、公开表格CSV/JSON、可离线阅读目录、公开网站ZIP、署名与许可证、文件SHA256和版本日期。图片视频采用已经允许展示及传播的副本，保留原始来源；必要时每家机构一包，不让用户必须下载全全国资料才能阅读一家。

本仓库的 `scripts/build-distribution-kit.py` 可生成传播导读包，包含项目说明、提供者署名、平台发布模板、公开网站ZIP、来源目录和校验清单。它不上传任何平台，也不把私人库加入公开包。普通人先打开“先读我.txt”，不用理解代码。

## 不先花钱的起步组合

1. 延续已建立的原站展示和GitHub发行包，补齐作者署名与手机导读。
2. 用现有微信/QQ等账号准备文字与图文稿，按平台规则手动发布；微信/QQ文件转交之外，让接收者实际另存一份。
3. 在腾讯文档或飞书等选择一种公开可读且可导出的目录，把CSV转成可查表格，再保留TXT/CSV离线版。
4. 用蓝奏云试当前小网站包，用123/移动/天翼等之一试图片视频包；从无会员接收手机测试，记录是否需登录/客户端/付费和能否完整下载。未测成功前不标不限速免费。
5. 再增加一个不同运营方的源码/文档镜像和一名独立副本维护者。不要因两个链接来自同一账号，就当作两份可靠备份。

以上是推荐实施顺序，不代表新文档、新网盘、新平台账号已经创建。

## 渠道目录

以下每项给出建议内容、操作路径和需要确认的条件。普通发帖与已有空间可先从免费范围尝试；免费容量、公开资格、传播链接和下载条件以现行账号为准。所有境外方案均保留作为备用，国内入口的可达性需要使用国内手机与实际网络验证。

## 平台可访问与下载实测方法

选同一份约5MB网站包，加一份已获准传播的较大测试视频。至少测试维护者账号、未登录手机和无付费会员接收者；分别记录网络、运营商、是否打开、是否需App/登录/费用、实际下载时间、文件大小和SHA256。失败写实际原因，不猜测是举报造成；标明测试日期。未测就是未测，官网不限速宣传与本项目实测分开。

用已拥有的账号先试，发现收件者需要付费时保留为条件渠道，不伪装成免费。免费的网盘空间、免费分享下载、免费直链和免费静态托管是四种不同条件。

## 图片视频该怎样随各平台传播

公开视频平台放易于观看的授权播放版；完整可下载文件放通过实测的网盘/Release/对象存储。本站页面将机构编号、来源、视频时间点、授权范围、下载清单关联起来。平台转码和删帖不能影响另存的原件；分包工具输出只有完整还原后才是原视频。

按版本保留“原件（私人或授权受控）”“公开播放版”“允许再传播包”三个不同范围。只在所有相关权利范围允许时公开传播，下载包随附来源与署名。大包按适用单文件限制分卷，分卷还原说明必须一起交付；不改后缀绕过平台限制。

## 被投诉、链接失效与更正后的接力

保留每条公开内容的来源、授权依据、版本与处理记录；人工核对投诉，必要时暂时隐藏争议内容并给处理说明。站点故障可使用已经保存的授权公开副本继续阅读。更正后的包标明替代版本，让镜像维护者同步更正和撤回通知；旧副本无法保证完全召回。

备用途径用于合法资料的保存和可恢复展示，不用短链轮换、伪装文件或套壳逃避平台处理。短链和二维码只做便捷入口，旁边保留完整地址、项目名称和版本，失效时仍能找到材料。

## 规模与预算的判断

公开网站包约5MB、源码包约12MB（具体见每次发行附件），复制成本很低；真实媒体另算。以下只是容量情景：每家100张2MB照片加10段100MB视频，约1.2GB；100家约120GB；1000家约1.2TB，不包含第二份备份、版本和编码副本。1251条来源记录不等于有1251家已核实机构的完整媒体。

零预算先保存目录与小包、公开播放版按机构逐包增加，已有设备与独立维护者提供容量；不要因全国范围便要求单个平台承担全部原件。若启用计费对象存储，先设上传总量和预算提醒，免费额度用完停止新增而非假定会无限免费。不存在保证全国用户免费、不限速且永久保存任意媒体的已验证单一方案。
